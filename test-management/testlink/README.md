# TestLink experiment

Use TestLink as a separate test-management application. Create a Test Project named `TestForge`, a Test Plan named `Student Portal Regression`, and import/copy test cases from `../test-cases.csv` (the CSV is a working source catalogue; exact CSV import support depends on the TestLink version/plugin installed). Record execution status and attach generated reports. TestLink is not bundled because it is a separately hosted PHP application with its own database and administrator setup.
