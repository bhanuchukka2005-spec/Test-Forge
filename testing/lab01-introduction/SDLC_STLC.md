# Introduction to Software Testing, SDLC vs STLC and Simple Test Cases

## Project
TestForge Student Portal

## 1. Introduction to Software Testing
Software testing evaluates whether an application meets its specified
requirements and behaves as expected.

Objectives:
- Detect defects and errors.
- Verify application functionality.
- Improve software quality.
- Validate user expectations.

## 2. Types of Testing
- Manual Testing
- Automation Testing
- Functional Testing
- Non-functional Testing

## 3. Software Development Life Cycle (SDLC)
1. Requirement Analysis
2. System Design
3. Implementation
4. Testing
5. Deployment
6. Maintenance

## 4. Software Testing Life Cycle (STLC)
1. Requirement Analysis
2. Test Planning
3. Test Case Design
4. Test Environment Setup
5. Test Execution
6. Test Cycle Closure

## 5. SDLC vs STLC
SDLC covers the complete software development process.
STLC focuses specifically on software testing activities.
