# Lab Sheet 6 - JUnit

This lab demonstrates JUnit 5 using the actual TestForge ResultCalculator.

Files:
- JUnit_Testing.md
- The automated test is maintained under src/test/java/com/testforge/service/.

Run from the repository root:

.\mvnw.cmd "-Dtest=ResultCalculatorJUnitLabTest,ResultCalculatorTest" test

TestNG is also configured separately in the project through the Maven testng profile.
